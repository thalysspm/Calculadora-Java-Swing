# Changelog

Todas as mudanças importantes deste projeto serão documentadas aqui.

## [1.0.0] - 01/06/2026

### Adicionado
- Primeira versão da calculadora
- Interface gráfica com Swing
- Operações básicas (+, -, ×, ÷)
- Raiz quadrada
- Porcentagem

## [1.1] - 03/06/2026
O que foi adicionado em relação à versão anterior:

- Histórico — cada cálculo aparece no painel direito; duplo clique reutiliza o resultado
- Memória — botões MC, MR, M+, M− na barra utilitária
- Modo científico — botão sci expande a janela com sin, cos, tan, log, ln, x², xⁿ, π, e, |x|
- Parênteses — botão ( ) inteligente que abre ou fecha conforme o contexto
- Potenciação — suporte a ^ no parser
- Conversor de unidades — km, mi, °C, °F, kg, lb, m, ft no painel direito
- Tema claro/escuro — botão ☀ / ☾ no topo
- Animação de resultado — fade suave ao pressionar =
- Pré-visualização — o resultado aparece em tempo real enquanto você digita
- Som de clique — beep sutil gerado via javax.sound sem dependências externas
